# Animation Asset Library

Use this directory for animation-specific reference and generated 3D assets.

## Directories

- `reference/`: Product screenshots, source images, CAD conversion references, and visual references used to generate or validate assets.
- `generated/`: Generated or converted 3D assets from Meshy, Tripo AI, 3D AI Studio, Microsoft TRELLIS, or CAD conversion workflows.

## Rule

Use CAD/STP conversion for real CoolDrivePro product master geometry whenever available. Use AI-generated assets for supporting props and environments.
