JTD-10kwh-DD stackable home battery

A modular LiFePO₄ system listed at 10 kWh per battery layer and 51.2 V nominal. The catalog gives the dimensions per layer, which makes the completed stack height a separate planning measurement.

Selection notes

A two-layer proposal starts with 20 kWh of listed battery capacity. Allow for the base, top section, cable access and the approved stacking configuration when asking for a complete elevation drawing. Confirm the inverter and modules supplied together.

Is 207 mm the height of the complete system?

The drawing lists 207 mm for each battery layer. Request the assembled dimensions for the proposed number of layers.

Home battery kWh vs kW: which number sizes backup?

Use kWh to estimate how long a system can supply energy. Use kW to check whether the inverter can carry the appliances that run together. A backup design needs both numbers.
