Selection notes

The catalog describes a wheeled, wall-mount-style cabinet. Ask for the drawing for the intended mounting method and the approved inverter input range. The nominal pack voltage should be confirmed against a current nameplate before system design.

Can I use the inverter from a 51.2 V cabinet?

Get the matched pack and inverter voltage ranges for this exact model. A shared communications connector alone cannot establish compatibility.

Home battery kWh vs kW: which number sizes backup?

Use kWh to estimate how long a system can supply energy. Use kW to check whether the inverter can carry the appliances that run together. A backup design needs both numbers.
